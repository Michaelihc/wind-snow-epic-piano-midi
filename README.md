# Wind Snow Epic — Piano MIDI

Piano arrangement of **《风雪史诗》 (Wind Snow Epic)**, originally composed by **西蒙Leonardo**. This is **Polished 23 Clean Phrase**, the arrangement used in the final piano video.

## Playback

Use an acoustic grand piano with CC64 sustain enabled. Both files contain 2,503 notes, expressive velocities, a one-second lead-in, and a final pedal release. Tempo: 90 BPM; meter: 4/4; key: C minor. The MIDI timeline is approximately 4 minutes 5 seconds. Preserve the existing timing when importing into a DAW.

This layered arrangement prioritizes musical detail; dense passages may exceed what one pianist can play.
